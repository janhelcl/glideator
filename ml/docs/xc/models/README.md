# XC model catalogue

XC model pages document architecture-level hypotheses and serving implications. Benchmark results belong in MLflow; durable changes to benchmark or promotion policy belong in decision records.

## Reference

- [Expanded production reference](expanded-production-reference.md) — migrated shape of the currently served model family and the baseline for XC migration/parity work.

New architectures should be added here only when they have a reproducible config and can be evaluated on the current XC benchmark.
